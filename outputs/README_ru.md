# Файлы обмена с LEAP

English version: [README.md](README.md).

В этой папке находятся файлы для обмена с desktop LEAP. Workbook в `leap_ippu_import/` сохраняет идентификаторы LEAP и содержит значения Current Accounts 2023 г. и выражения для трёх исследовательских сценариев. Перед импортом или цитированием результатов прочитайте двуязычный [протокол сценариев](../docs/leap_scenarios_2023_2050.md).

Не редактируйте вручную идентификаторы, названия листов, пути, имена переменных и единицы. При изменении сценарных допущений сформируйте workbook заново из свежего экспорта LEAP с помощью `scripts/fill_leap_import_template.py`, затем выполните проверку в LEAP, описанную в протоколе.
