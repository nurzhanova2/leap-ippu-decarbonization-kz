# Метаданные и словари данных

English version: [README_en.md](README_en.md).

Эта папка описывает источники, соответствия и правила ввода данных; она не заменяет исходные или обработанные таблицы.

| Файл | Назначение |
|---|---|
| `source_registry.csv` | реестр первичных источников: происхождение, период, единицы, статус и ограничения |
| `activity_data_template.csv` | шаблон для ручного добавления activity data с обязательной ссылкой на страницу, лист или ячейку |
| `bns_ippu_category_crosswalk.csv` | карта сопоставления продуктов БНС с категориями IPCC IPPU и статусом сопоставимости |

Имена полей CSV оставлены на английском языке для машиночитаемости и обмена данными. Оригинальные наименования продукции БНС сохранены на русском без перевода. Значения не дублируются в двух языковых версиях, чтобы не создать две расходящиеся базы данных; двуязычными являются описание, правила интерпретации и навигация.
