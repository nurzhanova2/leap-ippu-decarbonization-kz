# Метаданные и словари данных

English version: [README_en.md](README_en.md).

Эта папка описывает источники, соответствия и правила ввода данных; она не заменяет исходные или обработанные таблицы.

| Файл | Назначение |
|---|---|
| `source_registry.csv` | реестр первичных источников: происхождение, период, единицы, статус и ограничения |
| `activity_data_template.csv` | шаблон для ручного добавления activity data с обязательной ссылкой на страницу, лист или ячейку |
| `bns_ippu_category_crosswalk.csv` | карта сопоставления продуктов БНС с категориями IPCC IPPU и статусом сопоставимости |
| `leap_scenario_parameters.csv` | единый источник параметров сценариев LEAP: базовые значения 15 ветвей (т газа), единица ветви в шаблоне LEAP и множители f2030/f2050; читается `fill_leap_import_template.py` и `analyze_leap_scenarios.py` |
| `scenario_levers_literature.csv` | значения рычагов сокращения из литературы по процессам (L01–L36): показатель, значения на 2030 и 2050 гг., соответствующий множитель, источник, страница или таблица, DOI или URL, исходный файл и применимость к Казахстану |
| `leap_sensitivity_factors.csv` | предложенные значения low, central и high для f2030/f2050 в дополнительных расчётах чувствительности со ссылками на записи рычагов; представленные сценарии его не используют |
| `leap_scenario_parameters_crt2026.csv` | те же ветви, единицы и множители с базовыми значениями CRT 2026 за 2024 г. (журнальная версия); создаётся `scripts/build_leap_parameters.py --inventory crt2026` |
| `bns_activity_index_2024.csv` | индекс активности БНС 2024/2023 по процессам (central, low/high, варианты), редакция и дата выпуска, качество и доля базы; после перехода на CRT 2026 используется только как проверка |
| `leap_growth_variants.csv` | варианты роста активности после 2024 г. по процессам: ряд и окно тренда, отрасль и темп официального прогноза |
| `leap_2a4_variants.csv` | варианты для 2.A.4.d: эмиссионная доля s, альтернативный базовый год и вариант с множителями минеральной группы |
| `references_check.csv` | журнал проверки каждой записи [docs/references.bib](../../docs/references.bib): где цитируется, статус (verified, corrected, added), способ проверки (запись Crossref для DOI, PDF в data/raw/, официальная страница), DOI и исправления |

Имена полей CSV оставлены на английском языке для машиночитаемости и обмена данными. Оригинальные наименования продукции БНС сохранены на русском без перевода. Значения не дублируются в двух языковых версиях, чтобы не создать две расходящиеся базы данных; двуязычными являются описание, правила интерпретации и навигация.
