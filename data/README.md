# Реестр исходных данных

English version: [README_en.md](README_en.md).

Папки предназначены для воспроизводимой работы. Исходные файлы не переименовываются и не редактируются; обработанные таблицы создаются отдельно.

```text
data/
├── raw/           # неизменённые файлы, скачанные из первоисточника
├── processed/     # очищенные и гармонизированные таблицы
├── metadata/      # реестр, словари, журнал преобразований
└── README.md
```

## Порядок получения

1. Скачать ZIP с **Kazakhstan. 2025 Common Reporting Table (CRT)**, submitted 15 April 2025, из репозитория UNFCCC. Извлечь таблицы IPPU и activity data в `raw/unfccc_crt_2025/`.
2. Поместить использованный ранее файл **CRF 2023** в `raw/unfccc_crf_2023/`. В метаданных указать точную дату скачивания и URL.
3. Скачать годовые физические объёмы продукции БНС; предпочтительны таблицы по видам продукции, а не агрегированные ряды по ОКЭД. Сохранить оригинальные XLS/XLSX/CSV в `raw/bns/`.
4. Скачать **Kazakhstan 2025 National Inventory Document (NID)** и предыдущий NIR/BUR/BTR, использованный для CRF 2023, в `raw/unfccc_reports/`.
5. Не копировать коэффициенты из вторичных источников: фиксировать страницу, таблицу и версию IPCC 2006 Guidelines / 2019 Refinement в реестре.

## Обязательные правила гармонизации

- Хранить исходное значение и преобразованное значение в разных столбцах.
- Не подменять нулём `NE`, `NO`, `NA`, `IE` или конфиденциальные значения; это разные причины отсутствия числа.
- Приводить массу к тоннам, выбросы — к kt CO2eq, но оставлять исходную единицу в метаданных.
- Сравнивать только одинаково определённые продукты: например, цемент с цементом, а не цемент с клинкером.
- Для каждого вручную извлечённого числа указывать страницу/лист/ячейку источника.

## Официальные точки доступа

- UNFCCC, [Kazakhstan 2025 CRT](https://www.unfccc.int/reports?f%5B0%5D=corporate_author%3A222&f%5B1%5D=document_type%3A4593&items_per_page=10&order=name&search2=&search3=&sort=desc).
- UNFCCC, [Kazakhstan 2025 National Inventory Document](https://unfccc.int/documents/646542).
- БНС Казахстана, [статистика промышленного производства](https://stat.gov.kz/ru/industries/business-statistics/stat-industrial-production/). На странице доступны динамические ряды и электронные таблицы; для activity data нужны таблицы по конкретным видам продукции.
- IPCC, [2006 Guidelines, Volume 3: IPPU](https://www.ipcc-nggip.iges.or.jp/public/2006gl/vol3.html).
- IPCC, [2019 Refinement, Volume 3: IPPU](https://www.ipcc-nggip.iges.or.jp/public/2019rf/vol3.html).

## Статус на 28 сентября 2026 г.

В `raw/literature/` и `raw/official/` сохранены литература и официальные документы для сценарных множителей, значений GWP AR5 и политического контекста (решение 18/CMA.1, ОНУВ 2023 г., Стратегия-2060); их URL и SHA-256 — в [source_registry.csv](metadata/source_registry.csv). В `raw/` сохранены неизменённые исходники БНС, CRT 2025, CRF 2023, NID 2025 и NIR 2023; их контрольные суммы и правила извлечения записаны в [журнале сбора](../docs/data_acquisition_log.md). Извлечены IPPU emissions и activity data CRT/CRF, проверочные сопоставления БНС–CRT за 2021 г., исторический ряд 1990–2023 и таблицы структуры категорий. Приоритетные методические разделы IPPU NID/NIR прочитаны; границы процессов и статус сопоставимости приведены в [методическом обзоре](../docs/process_methodology_review.md), а рисунки — в [анализе статьи](../docs/article_analysis.md).

`processed/leap_ippu_scenario_results_2024_2050.csv` содержит полный годовой результат для выбранной границы процессных выбросов LEAP. Он воспроизводит исправленные сценарные выражения LEAP за 2024–2050 гг.; определения сценариев и исключения зафиксированы в [протоколе сценариев](../docs/leap_scenarios_2023_2050.md).

`processed/crt_2025_2a4_subcategories_1990_2023.csv` содержит разбивку категории 2.A.4 по CRT 2025 (керамика, другое использование соды, неметаллургическая магнезия, использование известняка и доломита) за 1990–2023 гг., включая данные активности 2.A.4.d, которые общее извлечение activity data пропускает. Столбец `row_level` разделяет строки категории, подкатегорий и детализации; суммировать нужно только строки подкатегорий. Файл создаёт `scripts/extract_crt_2a4_subcategories.py`; интерпретация приведена в [обзоре NID/NIR](../docs/process_methodology_review.md).

`processed/leap_ippu_scenario_results_2024_2050_crt2026.csv` содержит основные сценарии журнальной версии на базе CRT 2026 inventory 2024. `leap_ippu_sensitivity_*_crt2026.csv` содержат расчёты чувствительности к росту активности и множителям, `bns_index_2024_check_crt2026.csv` сравнивает индексы БНС 2024 г. с CRT 2026. Их создают `scripts/analyze_leap_scenarios.py --inventory crt2026` и `scripts/analyze_leap_sensitivity.py`; см. [журнальную версию](../docs/leap_scenarios_2023_2050.md#журнальная-версия-база-crt-2026-inventory-2024).

**Версии инвентаризации.** Файлы без суффикса относятся к архивной конференционной версии (CRT 2025, 1990–2023 гг.). Файлы с суффиксом `_crt2026` относятся к журнальной версии (CRT 2026, 1990–2024 гг.). Их создают те же скрипты с параметром `--inventory crt2026` (см. `scripts/inventory_versions.py`): выбросы, данные активности, подкатегории 2.A.4, выбросы по подкатегориям, исторический итог и доли категорий. `crt_2025_vs_crt_2026_ippu_comparison_1990_2023_crt2026.csv` сравнивает два представления по категориям (`scripts/compare_unfccc_versions.py --pair crt2025_crt2026`).
