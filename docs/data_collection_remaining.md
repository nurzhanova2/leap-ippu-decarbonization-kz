## Правило приёма каждого нового файла

1. Сохранить оригинал без переименования содержимого в `data/raw/<source>/`.
2. Внести URL, дату представления, охват, путь и SHA-256 в `data/metadata/source_registry.csv`.
3. Не редактировать исходный файл; создать отдельный производный CSV в `data/processed/`.
4. Для каждого извлеченного ряда указать таблицу/лист/ячейку, исходную единицу, notation key и правило преобразования.
5. До расчёта расхождений проверить соответствие определения продукта и границы учёта.
