## Зачем этот проект

Выбросы от промышленных процессов и использования продукции (*Industrial Processes and Product Use*, IPPU) — значимая, но не всегда просто сопоставимая часть национального кадастра парниковых газов Казахстана. Проект объединяет официальные представления UNFCCC и производственную статистику БНС, чтобы:

```text
собрать источники → извлечь ряды → проверить определения → сопоставить данные → задать базовый 2024 год → проверить исследовательские траектории
```

Проект разделяет подтверждённые исторические данные и сценарные допущения. Он отражает прозрачную выбранную границу процессных выбросов, а не прогноз всего национального сектора IPPU.

## Ключевое методологическое правило

> [!WARNING]
> Численное расхождение ещё не означает низкое качество данных. Сначала проверяются единицы, определение продукта, границы процесса и метод инвентаризации.

Например, выпуск портландцемента нельзя напрямую сравнивать с данными о деятельности по клинкеру, а общий выпуск необработанного цинка БНС — с технологически узким потоком цинка из Waelz-процесса в CRT. Эти случаи документированы в [обзоре NID/NIR](docs/process_methodology_review.md).

### 2. Воспроизведите журнальную версию

Исходные файлы хранятся в `data/raw/`, а производные CSV — в `data/processed/`. Скрипты только читают исходники, записывают результаты отдельно и не изменяют файлы в `data/raw/`.

```bash
python scripts/extract_ippu_emissions.py --inventory crt2026
python scripts/extract_ippu_activity_data.py --inventory crt2026
python scripts/extract_crt_subcategory_emissions.py --inventory crt2025
python scripts/extract_crt_subcategory_emissions.py --inventory crt2026
python scripts/extract_crt_2a4_subcategories.py --inventory crt2026
python scripts/compare_unfccc_versions.py --pair crt2025_crt2026
python scripts/analyze_ippu_timeseries.py --inventory crt2026
python scripts/build_leap_parameters.py --inventory crt2026
python scripts/fill_leap_import_template.py outputs/leap_ippu_import/Kazakhstan_IPPU_LEAP_final_import.xlsx outputs/leap_ippu_import/Kazakhstan_IPPU_LEAP_import_crt2026.xlsx --parameters data/metadata/leap_scenario_parameters_crt2026.csv
python scripts/analyze_leap_scenarios.py --inventory crt2026
python scripts/analyze_leap_sensitivity.py
```

Результаты имеют суффикс `_crt2026`. Без `--inventory` скрипты воспроизводят архивную конференционную версию.

## Что осталось до подачи статьи

1. Выбрать целевой журнал и перевести список литературы из APA 7 в его стиль.
2. Уточнить у составителей кадастра данные о деятельности категории 2.A.4.d и её возможное пересечение с производством извести.
3. Провести финальную научную и редакционную проверку: данные авторов, форматы рисунков и требования к подаче.
4. По желанию: импортировать книгу CRT 2026 в desktop LEAP и сравнить результаты с воспроизведёнными значениями.

## Статус использования

Материалы предназначены для подготовки научной статьи и будущей модели. При использовании чисел следует ссылаться на первоисточник UNFCCC/БНС и сохранять указанный в таблице год представления, единицы и набор GWP.
