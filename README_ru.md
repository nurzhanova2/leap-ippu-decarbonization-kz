## Зачем этот проект

Выбросы от промышленных процессов и использования продукции (*Industrial Processes and Product Use*, IPPU) — значимая, но не всегда просто сопоставимая часть национального кадастра парниковых газов Казахстана. Проект объединяет официальные представления UNFCCC и производственную статистику БНС, чтобы:

```text
собрать источники → извлечь ряды → проверить определения → сопоставить данные → подготовить LEAP-входы
```

На текущем этапе результатом является воспроизводимый набор данных и протокол проверки. Он не подменяет будущую LEAP-модель и не выдаёт сценарные прогнозы за готовые результаты.

## Ключевое методологическое правило

> [!WARNING]
> Численное расхождение ещё не означает низкое качество данных. Сначала проверяются единицы, определение продукта, границы процесса и метод инвентаризации.

Например, выпуск портландцемента нельзя напрямую сравнивать с activity data по клинкеру, а общий выпуск необработанного цинка БНС — с технологически узким потоком цинка из Waelz-процесса в CRT. Эти случаи документированы в [предварительных результатах](docs/preliminary_results.md).

### 2. Воспроизведите обработанные таблицы

Исходные файлы хранятся в `data/raw/`, а производные CSV — в `data/processed/`. Скрипты только читают исходники и записывают результаты отдельно.

```bash
python scripts/extract_ippu_emissions.py
python scripts/extract_ippu_activity_data.py
python scripts/compare_unfccc_versions.py
python scripts/compare_bns_unfccc_2021.py
```

Перед запуском проверьте аргументы и пути в каждом скрипте: они рассчитаны на структуру этого репозитория и не изменяют файлы в `data/raw/`.

## Источники

- UNFCCC: Kazakhstan CRT 2025, CRF 2023, NID 2025 и NIR 2023;
- Бюро национальной статистики Республики Казахстан (БНС);
- IPCC 2006 Guidelines и 2019 Refinement, Volume 3 (IPPU).

Полный реестр, охват и ограничения каждого источника приведены в [metadata](data/metadata/README.md).

## Следующий этап

1. Написать разделы Methods, Results и Discussion, используя подготовленные рисунки, таблицы и методический обзор.
2. Проверить ссылки, единицы, GWP и определения показателей перед подачей статьи.
3. При необходимости дополнить длинные ряды БНС по клинкеру и стали и найти раздельные данные первичного алюминия.
4. Использовать гармонизированные данные для LEAP-модели как отдельный последующий этап.

Подробно: [оставшиеся задачи по данным](docs/data_collection_remaining.md).

## Статус использования

Материалы предназначены для подготовки научной статьи и будущей модели. При использовании чисел следует ссылаться на первоисточник UNFCCC/БНС и сохранять указанный в таблице год представления, единицы и набор GWP.
